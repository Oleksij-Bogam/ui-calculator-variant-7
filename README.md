# UI Calculator — Варіант 7

Мобільний додаток-калькулятор, створений на React Native з використанням Expo.

## Завдання

Створити додаток-калькулятор з базовими операціями (+, -, ×, ÷), історією обчислень, підтримкою десяткових чисел та обробкою помилок, зокрема діленням на нуль.

## Опис проєкту

Додаток реалізує простий калькулятор для виконання базових арифметичних операцій.  
Користувач може вводити цілі та десяткові числа, виконувати обчислення, очищати введення, видаляти останній символ і переглядати історію останніх обчислень.

Окремо реалізовано перевірку ділення на нуль. Якщо користувач намагається поділити число на нуль, додаток не виконує некоректне обчислення, а виводить повідомлення про помилку.

## Функціональність

- введення цілих чисел;
- введення десяткових чисел;
- додавання;
- віднімання;
- множення;
- ділення;
- обробка помилки ділення на нуль;
- відображення поточного виразу;
- історія останніх обчислень;
- очищення поточного введення;
- очищення історії;
- видалення останнього символу.

## Використані технології

- React Native;
- Expo;
- JavaScript;
- React Hooks;
- StyleSheet.

## Встановлення залежностей

Перед запуском потрібно встановити залежності проєкту:

```bash
npm install
```

## Запуск проєкту

Для запуску додатку потрібно виконати команду:

```bash
npm start
```

Після запуску можна відкрити додаток:

- через Expo Go на Android;
- або через Android Emulator;
- або у web-режимі, якщо це підтримується поточною конфігурацією Expo.

## Запуск на Android

```bash
npm run android
```

## Перевірка роботи

Приклади для перевірки:

```text
2 + 3 = 5
10 - 4 = 6
3 × 4 = 12
8 ÷ 2 = 4
2.5 + 1.5 = 4
5 ÷ 0 = Помилка: ділення на нуль
```
